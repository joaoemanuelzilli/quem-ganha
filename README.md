# 📼 Gravação ao vivo — QUEM GANHA? 2026

Snapshots automáticos da previsão durante a apuração do 2º turno (25/10/2026), gravados pelo worker a cada 10 minutos.

- `latest.json`: último estado publicado
- `snapshots/AAAAMMDD-HHMM.json`: estado em cada momento (horário de Brasília)
- `history.ndjson`: todos os ciclos do modelo (% apurado, previsão, intervalo, chance)

O commit de cada snapshot registra a hora em que a previsão foi feita.
